# Turtle Graphics Shape Designer

## Overview

This project uses Turtle graphics and object-oriented programming
to create and display geometric shapes in Java.

The program demonstrates inheritance, abstract classes,
method overriding, loops and custom drawing behavior
through multiple shape tools.

## Features

* Draws geometric shapes using Turtle graphics
* Supports customizable colors and sizes
* Uses subclasses that extend TurtleDesigner
* Displays shapes centered around coordinates
* Includes optional fill colors for shapes
* Uses FileIO utilities for file management

## Shapes Implemented

*   SquareTool
*   TriangleTool
*   CircleTool
*   CustomShapeTool

## Technologies Used

* Java
* Turtle Graphics Library
* Object-Oriented Programming
* File I/O
